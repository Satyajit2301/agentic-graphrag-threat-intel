# Notebook

Put the Google Colab notebook here (in Colab: File -> Download -> Download .ipynb), for example as
`Agentic_GraphRAG_with_GNN_Link_Prediction_for_Attack_Path_Reasoning_and_Patch_Prioritization.ipynb`.

The three files next to this note are the last blocks of the notebook as plain text, so that they can be read on GitHub:

| File | Block | What it does |
|---|---|---|
| `block15b.py` | 15b | ROC and PR curves, confusion matrix, per-technique results, example predictions, near-duplicate analysis, feature-group ablation, learning curve |
| `block16.py` | 16 | packs the data files of the Streamlit application into `app_data.zip` |
| `block17b.py` | 17b | checks that every figure and table of the report exists and zips them into `report_assets.zip` |

They need Block 1 (and, for 15b, Block 15) to have run in the same Colab session.
