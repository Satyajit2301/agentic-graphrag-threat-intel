`MyDrive/GraphRAG_ThreatIntel/app_package/`). After unzipping it contains:

kg_nodes.parquet, kg_edges.parquet, lp_predictions.parquet, lp_cve_info.parquet, lp_test_results.json,
benchmark.json, example_questions.json, recorded_runs.json

The zip already contains the folder name `data/`, so unzip it in the project folder (next to `app.py`), not inside this folder.
The application does not need this README.
